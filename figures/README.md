# Figures

This folder contains figures generated from the dairy calf feed intake and growth analysis.

- `weekly_average_calf_weight.png` — Weekly average calf body weight by treatment.
- `daily_grain_intake_by_treatment.png` — Daily average grain intake by treatment.
- `daily_hay_intake.png` — Daily average hay intake.
- `daily_tmr_intake_by_treatment.png` — Daily average total mixed ration (TMR) intake by treatment.

The figures are descriptive summaries of the observed data. They do not establish causal treatment effects.
